# InsightFeed – AI Interest Thread & Smart Recommendation

**Live Demo:** [InsightFeed Web App](https://insight-feed-1--23091a0543.replit.app/?utm_source=chatgpt.com)

## Overview

InsightFeed is an AI-powered recommendation agent that analyzes the short-form content a student interacts with and identifies their underlying interests.

Instead of recommending content based only on keywords, InsightFeed considers **context, content meaning, and engagement behavior** to generate more useful technology-related recommendations.

## Problem

Students spend significant time scrolling short-form content, much of which may have limited educational or career value.

InsightFeed aims to make existing scrolling more useful by understanding what students are genuinely interested in and recommending relevant technology content.

## Key Features

* AI-based interest detection
* Semantic understanding of Reel content
* Watch, like, replay, and skip signals
* Broad interest inference
* Personalized technology recommendations
* Negative engagement signal handling
* Recommendation explanation
* Daily recommendation concept
* Reel selection and watch functionality
* AI fallback handling

## How It Works

```text
Student Reel Interactions
          ↓
Behavior Analysis
          ↓
Content & Context Understanding
          ↓
Interest Thread Detection
          ↓
Positive / Negative Signal Analysis
          ↓
Personalized Recommendation
          ↓
Recommended Technology Reel
```

## Example

A student interacts with:

* Java interview meme
* Software engineer lifestyle Reel
* Coding interview meme
* Developer laptop comparison
* AI career-hype Reel — skipped
* Technology news

InsightFeed should understand the broader pattern as:

**Primary Interest:** Software Engineering / Technology

**Secondary Interest:** Technical Interviews / Developer Career

Rather than simply recommending another Java Reel.

## Project Goal

The goal of InsightFeed is **not to stop social media usage**.

It aims to make existing short-form content consumption more **relevant, educational, and career-oriented** by understanding user interests and engagement patterns.
